# xOS g38 — release plan

**Status: NOT BUILT.** These are planned product capabilities, not features verified in this public beta. The source snapshot in this repository is from g37. No g38 image, installer, or release artifact is included.

## Planned experience

- A Lumi boot screen followed by sign in or account creation, with the clock, weekday, and date.
- Camera and glasses connections for video conversations with Lumi and sharing the screen with her.
- A social poker experience where Lumi can participate with the group.
- Lightweight games, including activities while downloads finish.
- One Lumi Control hub for chat, models, running work, and service controls.
- An agent workspace that shows work in progress, with pause, stop, menu, and taskbar controls.
- A streaming assistant for on-screen text, viewer questions, clips, and accountability.
- An xOS quality workflow where Lumi checks apps and reports bugs, with agent harnesses integrated into the operating system.
- Streaming voice conversations that respond to interruptions, plus read-aloud of answers.
- Context tags for conversations, such as business, investigation, and journalism.
- Guided team invitations, account verification, PIN setup, vault setup, and a first project.
- A minions page showing training material and allowing conversation and session controls.

## Release status

Every item above remains a g38 plan. Implementation, privacy and permission behavior, integration, accessibility, native-device checks, packaging, and release validation must be completed before any item is advertised as shipped.
