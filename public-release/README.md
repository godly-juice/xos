# public-release (g37) - withdrawn

The g37 bootable image and its downloader were withdrawn on 2026-11-03 (see VALIDATION.md). The downloader, the image manifest and the image checksums were removed from this folder because the files they point to are no longer published. The source archive, the kernel source and configuration, the package inventory and the licences stay in the release [g37-public-beta.1](https://github.com/godly-juice/xos/releases/tag/g37-public-beta.1). The next beta image will be posted in this repository's releases.
